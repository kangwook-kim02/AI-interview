# 프론트엔드 디자인 시스템 — AI 면접

> 상태: v0.1 (초안). 레퍼런스/피드백으로 계속 다듬는다.
> **목표: "AI가 만든 티 나는 범용 디자인" 탈출.** 아래 규칙을 벗어나는 결정은 하지 않는다.
> (Claude Code용 동일 스킬: `.claude/skills/frontend-design/SKILL.md` — **같은 내용 동기화 유지**.)

## 0. 브랜드 성격 (모든 판단의 기준)

**따뜻한 · 든든한 · 솔직한 · 격려하는.**
취준생이 혼자 면접을 연습하는 서비스다. **위협적이지 않고, 긴장을 낮추고, "든든한 파트너" 같은 느낌**을 준다. 차갑고 기업용 SaaS 같은 톤은 금지. 그렇다고 유치하지도 않게 — 따뜻하되 신뢰감.

판단이 애매하면 자문한다: *"이게 취준생의 면접 긴장을 낮춰주나, 높이나?"*

### 제1원칙: 단순함 (가장 중요)

**복잡하지 않게. 한 화면에 한 목적.** 요즘 한국 취업포털(잡다·자소설닷컴 류)처럼 조밀한 카드 캐러셀·아이콘 그리드·배지 범벅·번잡한 3D 히어로는 **명시적으로 피한다.**

- 한 화면의 핵심 액션은 **하나**. 경쟁하는 CTA 여러 개 금지.
- 네비게이션 항목·섹션 수를 최소화. 넣을까 말까면 **뺀다.**
- 여백을 과감하게. 정보 밀도를 낮추고 **숨 쉬게** 한다.
- "기능 많아 보이게"가 아니라 "할 일이 분명하게". 복잡함 = 긴장. 단순함 = 안정.

> 우리 제품은 채용 마켓플레이스가 아니라 **집중된 연습 도구**다. 애초에 단순해야 맞다.

## 1. 컬러 (라이트, 따뜻)

CSS 변수로 관리하고 Tailwind 토큰으로 노출한다. 하드코딩된 hex를 컴포넌트에 직접 쓰지 않는다.

```css
:root {
  /* 중성 (따뜻한 계열 — 차가운 회색 금지) */
  --bg:        #FBF8F3;  /* 본문 배경: 따뜻한 페이퍼 (흔한 크림보다 밝게) */
  --surface:   #FFFDFB;  /* 카드/패널 */
  --ink:       #2A2420;  /* 본문 텍스트: 따뜻한 near-black (순검정 #000 금지) */
  --muted:     #8A8077;  /* 보조 텍스트: 따뜻한 회갈색 */
  --line:      #ECE4D9;  /* 구분선/테두리: 따뜻한 헤어라인 */

  /* 프라이머리: 친근한 코랄 (에너지 있지만 공격적이지 않음) */
  --primary:        #FF7A59;
  --primary-hover:  #F2663F;
  --primary-ink:    #FFFFFF;  /* primary 위 텍스트 */
  --primary-soft:   #FFE9E1;  /* 연한 틴트 배경(선택 상태, 배지) */

  /* 서포트: 든든함·신뢰 (그라운딩) */
  --accent:       #2F6F5B;   /* 딥 파인 그린 — 링크/보조 버튼/강조 */
  --accent-soft:  #E3F0EB;

  /* 시맨틱 */
  --success: #2F9E6E;
  --warning: #E8A33D;
  --danger:  #E05A4B;  /* 따뜻한 레드 (차가운 #FF0000 금지) */
}
```

**규칙**
- 기본 배경은 순백(#FFFFFF) 말고 **따뜻한 페이퍼(`--bg`)**. 카드만 밝게 띄운다.
- 액션 1순위는 `--primary`(코랄), 2순위/링크는 `--accent`(파인 그린). **색을 3개 이상 난사하지 않는다.**
- 텍스트는 `--ink`/`--muted` 두 단계면 충분.
- 명도 대비(WCAG AA) 지킨다: 코랄 위 텍스트는 흰색, 코랄을 본문 글자색으로 쓰지 않는다.

## 2. 타이포그래피 (개성 있는 산세리프)

**범용 Inter/Roboto/system-ui 금지.** `next/font`로 자체 호스팅한다.

- **제목/디스플레이**: 개성 있는 산세 — 1순위 `Gmarket Sans`(KR+EN, 둥글고 친근), 대안 `Fredoka`(EN) / `SUIT`.
- **본문/UI**: `Pretendard` (KR+EN, 가독성). 숫자/타이머는 `Pretendard`의 tabular-nums.

```
--font-display: 'Gmarket Sans', 'Pretendard', sans-serif;
--font-body:    'Pretendard', sans-serif;
```

**규칙**
- 위계는 **크기+굵기**로. 색으로 위계 만들지 않는다.
- 제목은 과감하게 크게(히어로 40–64px), 자간 살짝 좁게. 본문 16px, 행간 1.6 넉넉히.
- 한국어 UI 기본. 영문 폰트 섞을 때 베이스라인/크기 맞춘다.

> 폰트는 아직 확정 아님 — 레퍼런스 보고 바꿀 수 있음. 바꿀 땐 이 섹션만 고치면 됨.

---

## 3. 형태 · 간격 · 그림자 (친근하게)

```css
--radius-sm: 10px;
--radius-md: 16px;   /* 카드 기본 */
--radius-lg: 24px;   /* 큰 패널/모달 */
--radius-pill: 999px; /* 버튼은 pill 또는 radius-md */

/* 그림자: 부드럽고 따뜻하게 (차갑고 진한 그림자 금지) */
--shadow-sm: 0 1px 3px rgba(90,70,50,.06);
--shadow-md: 0 2px 8px rgba(90,70,50,.06), 0 10px 28px rgba(90,70,50,.05);
```

**규칙**
- 모서리는 **넉넉히 둥글게**(친근함의 핵심). 각진 0px 금지.
- 간격은 4px 그리드. 섹션 사이는 넉넉하게(숨 쉬는 여백).
- 그림자는 은은하게. 테두리(`--line`)+연한 그림자로 띄운다. 짙은 drop-shadow 금지.

---

## 4. 모션 · 마이크로 인터랙션

- 전환은 **부드럽고 약간 통통 튀게**(spring-ish, 150–250ms). 호버 시 살짝 떠오르거나 scale 1.02.
- 과하지 않게 — 페이지마다 애니메이션 남발 금지. 포인트 1~2개.
- 면접 화면은 **차분하게**(긴장 유발 금지): 질문 등장은 부드러운 페이드/슬라이드, 깜빡임·번쩍임 금지.

---

## 5. 일러스트 · 아이콘

- 둥글고 손그림 느낌의 일러스트를 **빈 상태(empty state)·랜딩 히어로**에 사용(따뜻함의 핵심 장치).
- 아이콘은 **라운드/소프트 스트로크** 계열(예: Lucide의 둥근 변형 톤). 날카로운 선형 아이콘만 쓰지 않는다.
- 이모지 남용 금지(친근하되 유치하지 않게).

---

## 6. 이 앱 특유 화면 가이드

- **랜딩(`/`)**: 큰 따뜻한 히어로 + 일러스트 + "같이 시작하기" 코랄 CTA. "작동 방식" 3~4스텝을 카드/타임라인으로 부드럽게.
- **대시보드**: 자소서 카드 그리드. 카드는 둥근 `--surface` + 연한 그림자, 회사명/직무/문항수, "면접 보기" 코랄 버튼. 빈 상태엔 일러스트 + 격려 문구.
- **면접 화면**: 좌(내 카메라)·우(AI Q&A). **차분·집중** 톤. 상단 진행률은 부드러운 스텝 인디케이터(1/4…), 타이머는 tabular-nums로 조용히. "대답 완료"는 명확하지만 위협적이지 않은 코랄 버튼.
- **폼(회사 정보 입력)**: 넉넉한 라벨·여백, 둥근 인풋, 추가/삭제는 부드러운 인터랙션.

---

## 7. ❌ 금지 목록 (slop 탈출의 핵심)

- ❌ Inter / Roboto / Arial / system-ui 기본 폰트
- ❌ 보라색 그라데이션 (특히 흰/검 배경 위) — 전형적 AI slop
- ❌ 순백(#FFFFFF) 본문 배경, 순검정(#000) 텍스트, 차가운 회색 중성
- ❌ 각진 0px 모서리 / 짙고 큰 drop-shadow
- ❌ 색 5개 이상 난사, 무지개 그라데이션
- ❌ 예측 가능한 "3개 아이콘+제목+설명" 똑같은 피처 그리드만 반복
- ❌ 면접 화면에서 번쩍이는 애니메이션/빨간 경고로 긴장 유발
- ❌ **복잡한 취업포털 룩**(잡다·자소설닷컴 류): 조밀한 카드 캐러셀, 8개+ 아이콘 그리드, NEW/배지 범벅, 번잡한 3D 렌더 히어로, 정보 과밀. → 전부 금지. 단순하게.

---

## 8. 적용 방법 (구현 시)

- 토큰은 `src/app/globals.css`의 `:root`에, Tailwind `theme.extend`에서 `colors`/`borderRadius`/`boxShadow`/`fontFamily`로 매핑.
- 폰트는 `next/font/local`(Pretendard/Gmarket Sans) 또는 `next/font/google`로 자체 호스팅 → CSS 변수로.
- shadcn/ui 컴포넌트는 **기본 테마 그대로 쓰지 말고** 위 토큰으로 오버라이드(특히 radius/color/shadow)해서 "기본 shadcn 티"를 지운다.
- 새 화면/컴포넌트 만들 때 이 문서의 §1~§7을 체크리스트로 쓴다.
